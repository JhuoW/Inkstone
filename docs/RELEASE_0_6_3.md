# 0.6.3 代码块编辑与品牌显示修复

日期：2026-11-09。按小更新规则，从 0.6.2 递增为 **0.6.3**。

- 插入代码块后，光标直接进入代码区域。输入、点击、失去焦点时均保留代码框，支持原位编辑和语法高亮。
- 右上角提供语言下拉框，包含 Python、JavaScript、TypeScript、Java、C/C++、SQL、HTML、CSS、JSON 等编辑器内置语言，以及纯文本。既有未知语言标签不会被自动改写。
- 普通键盘粘贴和右键粘贴在代码块内采用纯文本，保留代码缩进与符号；包含围栏分隔符的粘贴会相应延长外层围栏，避免提前结束代码块。
- 语言切换、代码编辑、撤销/重做和保存继续使用同一份 Markdown 源文，保留 BOM 与原有换行格式；源码模式仍可直接编辑围栏。
- 关于窗口标语改为中文“让想法落在纸上”、英文“A place for your thoughts”。贡献者继续为链接到个人主页的 Wei Zhuo。
- 常规侧栏 Logo 宽度由 142px 增至 190px，高度由 32px 增至 42px。中文版分别使用原始 `inkstone-logo-horizontal.svg` 和 `inkstone-logo-horizontal-reversed.svg`；窄侧栏保留自适应布局。

许可证保持 AGPL-3.0-only。本版使用独立配置进行桌面测试，生成新的安装包与便携包，不自动执行安装或修改 Windows 默认打开方式。

最终冻结源码已通过 **153 项单测、108 组浏览器检查、120 项完整 Windows Electron 桌面回归，以及实际 ZIP 程序的 11 项专项验收**，共 **392 项/组**。桌面与包内测试使用正常沙箱；源码的 345 个文件哈希在验收期间保持一致。浏览器测试包含 12 组新增代码块交互场景；全部 138 个下拉语言值均已检查高亮器映射。

一次初始扩展回归因既有测试脚本将启动开关放在开发入口之前，额外打开并扫描整个仓库，造成离线拼写测试超时。修正测试参数顺序后，最终完整 120 项回归全部通过，没有跳过、失败或 flaky。产品拼写检查逻辑未因此修改。

实际安装包负载、ZIP 和构建目录进行源文及二进制一致性核对；本次不重新执行安装、卸载或修改系统默认应用。校验值见随交付文件 `SHA256SUMS.txt` 和 `validation-results.json`。历史版本结果不作为本版重跑结果。产物未配置代码签名。
