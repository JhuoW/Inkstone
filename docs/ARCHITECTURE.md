# Inkstone 0.9.2 架构与可靠性边界

本文描述当前代码路径与设计取舍，不代替运行验收。实现状态见 [功能矩阵](../FEATURE_PARITY.md)，跨平台实际结果见 [验收记录](ACCEPTANCE.md)。

本版只面向Windows与Linux，Windows为主平台。Inkstone 不需要账户，也不提供云同步或图片上传器。文稿引用的远程资源读取、用户明确下载图片，以及用户主动发起的 [AI 写作助手](AI_ASSISTANT.md) 请求会访问相应地址；AI 请求由主进程直接发往用户选择的模型服务（云端或本地），不经过 Inkstone 服务器。

## 数据流

```text
本地 Markdown（显式文本编码）
        │ 读取原始字节与 SHA-256 revision
        ▼
Electron FileStore ──────── 用户数据：settings / session / recovery / history
        │ 受限 preload IPC
        ▼
SourceDocument 原文 ──坐标映射── CodeMirror 文本、选区、历史
        ▲                             │
        └──────── 最小范围补丁 ────────┘
                                      │ 非活动块装饰
                                      ▼
                     markdown-it → KaTeX / Mermaid → 消毒后 DOM
                                      │
                                      ▼
                         HTML / PNG / PDF 或 Pandoc
```

## 为什么保留 Markdown 原文

数据源是文本，不是富文本 AST。`src/source.js` 的 `SourceDocument` 保存原始字符串；CodeMirror 使用归一化换行坐标。编辑事务提供变化范围，将这些范围映射回原文，按从后向前的顺序应用补丁，避免位移影响后续范围。未涉及的原文保留原换行、空白和未知语法。插入的新换行遵循文档的主要换行约定。

`src/source-history.js` 将每个换行的原拼写记录为L/C/R图（分别代表LF/CRLF/CR），通过CodeMirror的 `invertedEffects` 与同一撤销栈一起恢复。字符变化共享不变的换行图；插入/删除换行只更新对应部分，不保存全文历史快照。分组撤销按逆序effect恢复组起点，因此中间版本也能保留混合换行和BOM。400个中间状态逐次撤销/重做已验证逐字节一致；正常撤销深度由CodeMirror管理，打开另一个文档会建立新历史。

BOM和编码由文件层保留。默认严格UTF-8；用户可明确指定UTF-16LE/BE、GB18030、Windows-1252或Shift-JIS。读取时校验字节可往返，写入时反向解码比较文本，无法表示的字符明确拒绝，不以替换字符隐式修复。

未修改保存首先比较最终字节哈希，完全一致时不写盘，不改变修改时间。显式格式整理属于用户请求的转换操作，可以改变原始格式；不能混入普通保存流程。

## 同区即时渲染与输入

`src/editor.js` 使用 CodeMirror 6 管理编辑状态、输入法、选区与撤销栈；`src/markdown.js` 给出顶层块的源区间和渲染结果。非活动块以装饰组件在相同编辑区域呈现，光标或选区覆盖的块恢复为文本。源码切换更新装饰状态，避免把 Markdown 解析后重新写回。

组合输入期间尽量维持原 DOM 和既有装饰映射，不在候选期重建正在编辑的块。该策略需要用真实 IME 验证，包括候选取消、选区替换和标点输入。合成事件只检验事件路径；本轮另用真实IBus仓颉/XTest验证候选、提交/取消、选区替换和正文单元格，但不能外推Windows微软拼音、Fcitx或Wayland。

当前实现对活动普通段落/标题的粗体、斜体、删除线、行内代码/URL链接按token与光标位置显隐语法。0.3为行内/块级公式增加精确源区间映射，在同一编辑器显示TeX并实时预览，避免仅以渲染文字查找源位置；正文表格以单元格为编辑目标；列表/引用及其他复杂活动块仍编辑源文。鼠标在复杂嵌套或重复文本中从渲染位置映射到源位置、复杂嵌套块鼠标选区以及所有Typora风格细粒度语法显隐，需要分别验收；普通段落正向/反向/源码到渲染块的真实鼠标拖选已回归。CodeMirror 具备某能力也不代表该装饰集成已经正确。

## 语法、数学与图表

- markdown-it 处理基础语法，附加插件处理脚注、任务列表、Emoji、上下标、高亮；扩展处理 YAML、提示块、目录、锚点与数学。
- highlight.js 负责预览高亮，CodeMirror 语言支持负责编辑语法高亮。
- KaTeX 和 mhchem 优先本地渲染数学/化学；失败时通过MathJax3.2.2的同步SVG输出兼容physics/bbox等命令，禁止require/autoload并使用内嵌glyph路径，不下载脚本/字体。其命令集合与MathJax v4不相等，不将基础用例外推到完整兼容。
- Mermaid 按需加载，结果保留为静态 SVG。传统 `flow` / `sequence` 分别使用 flowchart.js 与固定版本的 js-sequence-diagrams 原生语法引擎，生成独立、经消毒的 SVG；sequence提供simple与hand手绘几何主题，文字使用本地系统字体；未携带可选Daniel字体或下载字体。
- DOMPurify 消毒渲染输出。原文件中的未知 HTML 不因预览过滤而被删除。

解析策略独立放在 `markdown-options.js`：严格规则保留markdown-it默认行为，宽容规则仅改变标题/列表解析状态，不预处理整篇源串，token行映射保持原文。编辑/导出软换行分开配置，CJK强调为可选增强，见[规则说明](MARKDOWN_PARSER_OPTIONS.md)。

图表异步渲染必须检查对应容器仍有效，错误保留可编辑源文。导出应等待图表完成；仅在页面出现“正在渲染”时写出文件属于失败。ZenUML用本地MIT插件动态注册；Sankey的上游ASCII词法限制通过临时渲染ID和安全文本节点还原兼容，编辑原文不变。25类基础离线图表测试见[逐类记录](MERMAID_CATALOG.md)。

新窗口的初始文件只通过bootstrap传递一次，不再同时发送第二条open-path消息；初始化加载尾部依据当前真实dirty状态同步主进程，避免首次加载尚在持久化最近记录时覆盖用户刚输入的文字或关闭保护。延迟首次读取和最近记录响应的真实Electron回归覆盖CLI、新窗口、立即输入、取消关闭与保存。

## 保存、冲突、历史与恢复

`electron/storage.cjs` 将同一路径的应用内保存排队；读入文件时产生精确字节的 SHA-256 `revision`。保存时再次读取磁盘版本，发现差异即返回冲突。原文件的上一版本先存入独立历史目录，然后在目标文件的同一目录创建唯一临时文件、写入、`fsync`、再次校验版本、重命名替换，并尽可能刷目录。失败清理临时文件。

这些步骤保护普通崩溃、半写入和多数外部编辑场景，但不是文件系统事务。最终版本校验与重命名之间仍存在外部进程抢写的微小窗口；外部挂载盘、权限、符号链接和平台重命名语义必须单独验证。Windows交叉构建成功不证明它们的故障保存行为正确。

渲染进程保存的是“发起保存时”的快照。异步保存结束时，若用户继续输入，较新的内容仍应保持脏状态并再次调度保存，不能把旧快照当作全部内容已保存。外部通知与应用自身保存使用相同 revision 过滤，避免自保存误报冲突。

恢复草稿独立于自动保存：未命名文档也可以在用户数据目录存快照；加载历史/磁盘前先保留编辑内容。延迟快照前的最近输入仍可能在强制终止时丢失，故恢复不是零丢失承诺。当前历史保留数量、大小和会话结构以 `FileStore` 与桥接接口文档为准；完整多窗口会话恢复需要单独验收。

关闭/退出使用独立的确认与提交阶段：渲染端先提交当前输入法组合和表格单元格，保存、放弃或取消均给出明确结果；主进程只有在窗口确认后才放行。多窗口Quit先收集所有决定，任一取消会保留窗口，不先关闭已确认窗口；等待保存、异步图片或导航时按实际状态锁定/检查代际，迟到结果不得修改已经批准关闭的文稿。失败保留dirty与正文，不把“点击了保存”视为已经写盘。原生菜单、窗口X与快捷键走同一流程，见[实际流程用例](../tests/ux.spec.js)。

启动恢复只展示未被活跃窗口占用的孤立草稿，使用非模态提示；放弃当前草稿后清除对应恢复记录，避免重启又恢复已明确放弃的内容。物理强杀不能执行正常退出协议，因此仍依赖最近成功落盘的恢复快照。

## 桌面进程边界

主进程拥有文件、系统窗口、打印和外部工具权限。渲染进程使用 `contextIsolation`、关闭 Node 集成并启用 sandbox；preload 仅暴露操作白名单，不暴露通用 `fs`、shell 或任意 IPC。主进程验证消息来源窗口、主 frame、应用 URL 和参数。

本地资源通过 `inkstone-asset://local/` 读取，只允许已授权目录内的已知图像、媒体、字体或 CSS 类型。路径解析包含真实路径检查，避免符号链接逃逸。打开跨目录链接或图片可能需要用户先通过文件/目录选择器授权。该限制是产品行为的一部分，应给出明确错误。

文档 HTML 是不可信内容：预览过滤脚本、事件处理器和危险协议；嵌入内容不得获得桌面桥接。主进程阻止应用导航和未经允许的新窗口；权限请求默认拒绝。网络图片和允许的远程嵌入仍可能发生网络访问，不能把“离线可编辑”解释成所有远程内容都离线可用。

英语拼写词典随程序本地分发：Chromium固定版本的en-US Hunspell词典、SHA及来源保存在 `electron/dictionaries/provenance.json`。窗口创建前预装本地缓存，词典请求仅使用 `inkstone-dictionary://local/`；不存在的语言返回缺失，不回退CDN下载。真实新用户会话的原生拼写建议与外部HTTP请求为0已验。词库完整SCOWL/Ispell/WordNet许可保存在同目录并收入第三方通知。

## AI 写作助手

`electron/ai-service.cjs` 与 `electron/ai-provider.cjs` 在主进程中发起模型请求；渲染进程只通过白名单 IPC 提交文本并接收流式结果，拿不到 API Key。Key 经操作系统凭据保护（Electron `safeStorage`）加密后按“提供商 + 端点”分别保存。分析请求优先使用各服务的结构化输出（OpenAI 兼容服务的 `response_format`、Anthropic 的强制工具调用、Gemini 的 `responseSchema`）；服务拒绝该参数时自动退回纯提示词 JSON，主进程随后按同一 schema 校验结果。修改建议在渲染端以 CodeMirror 变更集映射到当前文档位置，应用时再次核对原文，详见 [AI 写作助手](AI_ASSISTANT.md)。

## 外部工具与导出

本地Pandoc通过 `execFile` 及参数数组调用，不把用户文件路径拼接到 shell 命令。工具检测独立于执行，缺失、版本错误、超时和输出不合法均须明确报错。Pandoc 支持的输入和输出集合不同，不能仅根据扩展名显示双向支持。

原生导出使用独立、不可执行用户脚本的窗口。渲染端提供已完成数学/图表的 HTML；主进程再次消毒HTML、嵌入本地资源和字体，将图片改为eager并等待加载后生成HTML、PDF、PNG或JPEG。导出文件存在不表示内容完整；应实际打开并检查中文、图片、数学、图表、分页和书签。PDF 书签请求是引擎能力，仍需检查生成文件。

Save As 可按目的文件夹重算本地链接，只替换解析得到的链接目标范围，不重序列化整篇文档。代码示例与远程地址保持原样；存在YAML自定义根路径时返回人工检查提示，不猜测其含义。此能力不等于自动迁移整个资源目录。

独立图片资源管理采用prepare/commit/cancel两阶段：扫描内联/有效引用式/HTML img-src，跳过YAML与代码；准备新副本并验证原图哈希、文稿revision和目标不覆盖，文稿原子保存成功后才处理旧图垃圾桶。失败回滚本次新副本；崩溃可能遗留stage/copy，但不先删源图。只更新当前文稿，其他文稿引用、picture/srcset和垃圾桶内容的编辑器Undo不属于事务恢复范围。

PNG 高度有限；超长文档需要清晰失败信息或分段方案。音视频在 PDF/PNG 中不能播放。Pandoc 的数学、图表、脚注和 HTML 可能与原生导出不同，转换失败或降级必须进入验收矩阵。

## 设置、主题与原创素材

界面与偏好由 `src/app.js`、`src/preferences.js`、`src/ui.js` 及样式文件提供。适合即时生效的设置通过 CodeMirror compartment 或 CSS 更新；设置持久化仍须通过重启测试确认。自定义 CSS 作为用户配置执行，应不从普通文档静默导入。

应用品牌使用用户提供的 `inkstone-brand` 原始标志、图标和品牌色；工作目录中的原包保持不动，运行时只引用 `src/assets/brand` 和 `build` 中所需副本，详情见[品牌说明](BRANDING.md)。`samples/assets` 图形/音视频为项目示例素材。产品不包含 Typora 的图标、源代码、自带 CSS 主题或商业激活机制。

0.2设置迁移仅按顶层退役字段及相关快捷键白名单清除旧设置，并原子保存/显示提示；不按内容关键词扫描文稿、CSS、片段、图片、草稿或历史。损坏设置备份同时去除退役字段，以免恢复时重新引入。若备份失败，则原设置文件保持不变，仅在内存使用默认值并暂停最近文件等自动持久化；显式设置更改会重试备份，仍失败就拒绝写入，避免启动后间接覆盖未经备份的原文件。

Inkstone 自身源码（包括 `integrations/vscode` 扩展）统一使用 AGPL-3.0-only，完整条款见仓库根目录 `LICENSE`。第三方依赖保留各自许可证。直接依赖选择成熟开放源码组件；典型许可证包括 CodeMirror/Lezer、markdown-it 及多数插件、KaTeX、Mermaid、Vite、electron-builder 的 MIT，highlight.js 的 BSD-3-Clause，以及 DOMPurify 的 Apache-2.0/MPL-2.0 双许可。传统图表的 flowchart.js/Raphael/Underscore 为 MIT，vendored js-sequence-diagrams 为 BSD-2-Clause，固定revision、原文件SHA-256和改动说明在 `src/vendor/sequence-diagrams/README.md`，原许可一并保留。MathJax3为Apache-2.0许可，随输出打包保留许可。ZenUML插件1.0.1与锁定core3.50.1均MIT，以本地包加载。最终以锁文件对应版本的许可证及 `THIRD_PARTY_NOTICES.md` 为准，不能只依靠包名推断所有传递依赖许可。

Electron 发行件还包含 Chromium、Node 等组件及各自 notices，应随发行包保留。Pandoc为可选外部程序，不把其代码并入应用；用户安装这些程序时遵守其许可证。系统字体不随本项目复制；KaTeX 等随包字体必须保留对应许可。锁文件用于复现，后续版本升级应重新审核许可证和运行回归测试。

Windows/Linux启动和扩展均检查宿主平台；构建只配置Windows NSIS/ZIP与Linux AppImage/deb/tar.gz。electron-builder依赖树中仍有其他平台和发布工具，它们属于开发期依赖，不代表本应用支持该平台或提供在线发布功能；构建命令显式 `--publish never`。

## 安装语言与界面操作边界

默认locale为en；合法已保存locale优先于安装语言种子。NSIS仅在安装目录resources写入en/zh-CN两值JSON，后端严格读取；ZIP/Linux无种子时通过首次启动提示条选择，不阻断文件打开。操作系统生成的文件选择器内部按钮仍由系统语言决定。[0.3说明](UI_UX_0_3.md)记录安装与UI验收范围。

公共对话框具有明确主动作、取消结果与busy状态，资源准备取消与提交阶段分别处理；导出执行期间锁住参数，避免用户在异步任务中改变后续动作。界面状态不能替代后端原子保存和版本检查。恢复提示使用非模态横条，避免初始化定时弹窗抢走编辑焦点。
