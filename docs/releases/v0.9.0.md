# Inkstone 0.9.0

This release makes the AI Writing Assistant dependable while you keep writing, and shows its errors in your interface language.

## AI Writing Assistant

- **Suggestions stay usable after edits.** Accepting one suggestion no longer invalidates the others. Each suggestion follows its passage through later edits and is shown as pending, applied or outdated. Undoing an edit makes an outdated suggestion available again.
- **Accept all and Revert.** Apply every pending suggestion as one undo step, or restore the original passage of a single applied suggestion.
- **Reliable analysis format.** Analyses request structured output from each provider: a strict JSON schema for OpenAI-compatible services, a forced review tool for Anthropic and a response schema for Gemini. If a service rejects that option, Inkstone falls back automatically. Quotes that differ only in spacing are matched to the exact source text.
- **Clearer chat.** Replies answer the question directly, follow the language of your question, and can be copied or inserted at the cursor as one undo step. Esc inside the panel cancels a running request.
- **Better error handling.** Overloaded services (HTTP 5xx) are retried twice, with a visible "retrying" status. An invalid Gemini key is reported as a key problem instead of a model error.
- **Shortcut.** Press **Ctrl+Shift+A** or choose **View → AI Writing Assistant**. The `aiAssistant` shortcut can be changed in Preferences.

## Interface and documentation

- Desktop errors no longer show Electron's IPC prefix. In the Chinese interface, file, encoding, export, image and AI errors are shown in Chinese.
- Inkstone, including the VS Code extension, is licensed AGPL-3.0-only throughout. Product and architecture documents now describe the optional AI integration and the current version.
- Historical validation screenshots were removed from the repository; images used by current documentation are kept.

## Validation

On Windows: 207/207 unit tests, 145/145 Electron end-to-end cases (21 for the AI assistant), browser-level editor suites, native packaged-app smoke and interaction tests, and the VS Code extension tests passed.

Live checks used a real Gemini key in an isolated, deleted profile with `gemini-3.6-flash` and `gemini-3.5-flash-lite`:

- Analyses used the Gemini response schema. Every suggestion in English and Chinese test documents could be located and applied.
- Code blocks, math, links, tables and citations were preserved after accepting all suggestions.
- Undo and redo, CRLF-preserving saves, the chat language rules and mid-stream cancellation all worked.

`gemini-2.5-flash-lite` is listed by the API but is no longer available to new users; choose a newer model if Inkstone reports it as unavailable.

AI scores and revisions still require human review. See the [setup guide](../AI_ASSISTANT.md) and [official provider references](../AI_PROVIDERS.md).
