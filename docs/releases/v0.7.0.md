# Inkstone 0.7.0

Inkstone gains an optional AI Writing Assistant integrated into the Markdown editor.

- Resizable bottom panel beside the sidebar, with persisted visibility and height, English/Chinese UI and light/dark themes.
- Whole-document or selected-passage reviews, writing-type-specific scoring, reasoned suggestions and document chat.
- Explicit revision preview, source navigation, accept/dismiss and normal undo. Changed or switched documents invalidate old results.
- Local Ollama/LM Studio OpenAI-compatible endpoints, OpenAI and Anthropic adapters. Direct requests, streaming, cancellation, timeouts and bounded context; no Inkstone backend or account.
- API credentials use operating-system encryption and are kept separate from ordinary preferences. Local unauthenticated models remain usable offline.

Stability fixes:

- Large code pastes and code-block commands no longer exceed the JavaScript argument limit when sizing backtick fences.
- Markdown formatting preserves whitespace inside code, math, HTML, YAML and unfinished literal blocks instead of rewriting their content.
- Session persistence tests now wait for renderer initialization and synchronize actual editor mode before asserting persisted state.

Validation on Windows: 175 unit tests, all 131 Electron end-to-end cases, editor/math/UI/design browser suites, and 7 AI scenarios against the packaged application. Tests cover real OS key encryption, local streaming transport, source BOM/CRLF preservation after accept/save/undo, stale results, readonly documents and cancellation. Existing features remain covered by the full regression suite.

Paid cloud inference and actual Ollama/LM Studio model quality were not tested without user credentials or installed model weights. Transport/protocol tests use deterministic local servers; scores and suggestions remain model judgments that users should review. These checks establish the tested behavior, not a claim that all possible bugs have been eliminated.
