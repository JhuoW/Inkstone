# Inkstone 0.8.0

AI Writing Assistant now has a highlighted entrance centered in the document titlebar's available space and a guided, provider-aware model setup flow.

- Eleven providers: OpenAI, Anthropic, Gemini, Qwen, DeepSeek, xAI, Mistral, Groq, Ollama, LM Studio and custom OpenAI-compatible servers.
- Official defaults verified on 2026-11-09, editable endpoints, Qwen regions, per-provider profiles, account model discovery, documented fallback choices and custom model IDs.
- Native Gemini and Anthropic adapters alongside provider-aware OpenAI-compatible transport. Discovery handles pagination, local servers and known non-chat models.
- First-use setup resumes the pending analysis or chat after a successful connection test and save. Cancellation preserves the question; document changes prevent stale requests.
- Test and discovery operate on unsaved drafts. Endpoint changes never reuse another address's key. Saved models are not silently replaced, and removing credentials does not require an authenticated generation call.
- Credentials remain OS-encrypted; old settings and keys migrate without plaintext exposure. Linux insecure keyring fallback remains refused.

Validation on Windows: 190/190 unit tests, 19/19 AI end-to-end cases, and 6/6 desktop design cases passed. All 19 AI scenarios also passed against the packaged application. The installer version/icon resources and all 303 packaged runtime files matched the current build.

Live Google Gemini validation used the user's key entered directly in an isolated application profile. `gemini-3.6-flash` returned a 62/100 review with four scoring dimensions and three applicable suggestions for a synthetic document. The account model list returned 47 text-generation models, including the configured model. A follow-up chat streamed five text deltas; accepting a suggestion and undoing it restored the exact pre-acceptance source, and saving preserved it on disk. No real key is included in these artifacts.

Other providers were verified against official API documentation and automated protocol/local-server tests; they were not all exercised with live cloud credentials or downloaded local weights. Local validation was performed on Windows. Release publication additionally requires Windows and Linux CI builds and native/package checks to pass. AI scores and revisions still require human review.
