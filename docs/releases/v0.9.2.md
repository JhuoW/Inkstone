# Inkstone 0.9.2

This small update fixes details found while refreshing the README screenshots. Features, commands and settings are unchanged.

## Fixes

- **Chinese welcome page.** On first launch the cursor now starts on the first paragraph, so the quote below the title renders instead of showing its `>` marker.
- **Title bar.** Short folder names such as “My notes” are shown in full. Long names still shorten, folder first, so the file name stays readable and never runs into the AI Writing Assistant button.
- **English wording.** A single AI suggestion reads “1 suggestion”, and the status bar reads “1 word” for a one-word document.

## README

New English and Chinese screenshots of the current interface. The AI Writing Assistant screenshot shows the overall score, feedback on each dimension and a suggested revision in one view.

## Validation

On Windows: 210/210 unit tests, 158/158 Electron end-to-end cases (2 new for this release), and the native packaged-app smoke and interaction tests passed.

See the [AI Writing Assistant guide](../AI_ASSISTANT.md) for model setup.
