## Inkstone 0.6.4

- Edit code in place with syntax highlighting and a language picker.
- Fix plain-text language selection with fence metadata, preserve the caret when changing languages, and close unfinished fences with Ctrl+Enter.
- Render inline formulas in place and edit tables through context menus.
- Use Inkstone with Windows Markdown file associations and default-app settings.
- Refresh the bilingual About dialog, branding, and concise English/Chinese README pages with matching screenshots.

**Download:** Windows x64 installer only. Run the `.exe` to install or upgrade. The installer is not code-signed.
