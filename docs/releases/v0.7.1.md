# Inkstone 0.7.1

The AI Writing Assistant is easier to find: its full-name button now sits at the top right of the document, beside Commands, with a pen-nib icon and a subtle highlight. The active appearance follows the panel's open state.

- Chinese UI consistently uses **AI写作助手**; English uses **AI Writing Assistant**.
- Compact layouts retain the complete button label and keep document title, save status and commands accessible.
- The panel heading and command-palette entry use the same name. Existing model settings and analysis behavior are unchanged.

Validated on Windows: all 13 existing AI and desktop design end-to-end tests passed. An additional 16-case layout check passed in both the development build and the packaged application, covering English/Chinese, light/dark themes, keyboard activation, panel close state, 150% zoom and a 220px-wide editor beside a 500px sidebar. No document content changed during these UI checks. AI transport regression tests use a local mock service; this update does not add or claim live-model validation.
